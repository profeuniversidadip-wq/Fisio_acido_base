
# FisioÁcidoBase IA — versión 2

Primera versión funcional de una aplicación educativa para comprender el equilibrio ácido-base.

## Módulos
1. Fundamentos
2. Simulador cualitativo
3. Interpretación guiada de gasometría
4. Práctica razonada

## Base conceptual
Construida a partir del material `06 EQUILIBRIO ÁCIDO-BASE.pdf`.

Valores utilizados porque aparecen explícitamente en el material:
- pH arterial: 7,35–7,45
- PCO₂ arterial: 35–45 mmHg
- HCO₃⁻ arterial: 22–26 mEq/L

Esta primera versión no calcula fórmulas cuantitativas de compensación ni diagnostica trastornos mixtos complejos.

Creado por Cristian Barahona Videla · Uso educativo · © 2026

## Mejora v2
- Simulador con faders para ventilación, PCO₂, HCO₃⁻ y excreción renal de H⁺.
- Tarjetas de estado con identificación visual de tendencia acidificante, alcalinizante, normal o mixta.
- Resumen integrado de las fuerzas ácido-base.

## Mejora v3
- Diseño responsivo para monitor y celular.
- Título con mayor margen superior para evitar recorte.
- Faders apilados en una sola columna en pantallas pequeñas.
- Tarjetas y pestañas optimizadas para móvil.

## Mejora v4
- Simulador compacto.
- Resumen de condición ácido-base visible inmediatamente bajo los faders.
- Tarjetas más pequeñas y colores más evidentes.
- Menor desplazamiento vertical en monitor y celular.

## Mejora v5
- Práctica dividida en 3 tandas.
- Tanda 1: fundamentos.
- Tanda 2: aplicación e interpretación básica de gasometría.
- Tanda 3: casos clínicos.
- Cada respuesta muestra una explicación breve del mecanismo.
- Navegación por ventanas con identificación de color.

## Mejora v6
- Panel de faders verticales tipo mesa de sonido.
- Diseño 4 canales en PC y 2x2 en móvil.
- Colores diferenciados por variable.
- Resultado ácido-base integrado inmediatamente bajo el panel.

## Mejora v7
- Faders verticales más finos y móviles directamente con mouse o dedo.
- Se eliminan los controles inferiores.
- Cada parámetro muestra su condición justo debajo.
- Resumen ácido-base más pequeño e inmediatamente bajo el panel, para evitar desplazamiento vertical.

## Mejora v8
- Navegación principal convertida en recuadros de color.
- Cada sección tiene un color propio.
- La pestaña activa cambia a un tono más intenso con borde destacado.
- En celular, los cuatro botones se organizan en una cuadrícula 2x2.
