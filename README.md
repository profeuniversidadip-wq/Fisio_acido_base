
# FisioÁcidoBase IA — versión 1

Primera versión funcional de una aplicación educativa para comprender el equilibrio ácido-base.

## Módulos
1. Fundamentos
2. Simulador cualitativo
3. Interpretación guiada de gasometría
4. Práctica razonada

## Base conceptual
Construida a partir del material `06 EQUILIBRIO ÁCIDO-BASE.pdf`.

Valores utilizados porque aparecen explícitamente en el material:
- pH arterial: 7,35–7,45
- PCO₂ arterial: 35–45 mmHg
- HCO₃⁻ arterial: 22–26 mEq/L

Esta primera versión no calcula fórmulas cuantitativas de compensación ni diagnostica trastornos mixtos complejos.
